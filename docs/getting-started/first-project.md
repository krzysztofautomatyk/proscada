# Pierwszy projekt

## Utworzenie

1. Wybierz **File → New Project**.
2. Dodaj urządzenie i tagi w **Variables / Tags**.
3. Otwórz **Toolbox**.
4. Przeciągnij kontrolki na ekran.
5. Ustaw `Tag`, wygląd i dynamikę w **Properties**.
6. Zapisz projekt.

## Organizacja Designer

- **Solution:** ekrany, skrypty i zasoby projektu.
- **Toolbox:** 35 typów kanonicznych oraz szablony.
- **Outline:** obiekty bieżącego ekranu.
- **Styles:** fonty, klasy stylów i animacje.
- **Components:** kontrolki złożone i rollout CSV.
- **Alarms:** grupy oraz definicje alarmów.

## Przejście do Runtime

1. Skonfiguruj Modbus.
2. Kliknij **Connect**.
3. Kliknij **Start**.
4. Sprawdź stan ONLINE, jakość tagów i alarmy.

Zapisy wymagają trybu Runtime, roli z prawem zapisu, jakości `Good` i taga oznaczonego jako writable.
