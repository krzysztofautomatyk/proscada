# Prymitywy, zasoby i układ

## Prymitywy

| Kontrolka | Zastosowanie |
|---|---|
| Text | etykieta, nagłówek, podpis wartości |
| Rectangle | tło, obszar procesu, prosty stan |
| Connector | linia, strzałka, połączenie procesu |

## Zasoby

| Kontrolka | Zastosowanie |
|---|---|
| Image | obraz lokalny lub ikona |
| Vector Symbol | sanityzowany symbol wektorowy |

Obrazy nie powinny ładować zdalnych skryptów ani aktywnych SVG.

## Układ

| Kontrolka | Zastosowanie |
|---|---|
| Panel | semantyczne grupowanie elementów |
| Disclosure Panel | zwijana sekcja ekranu |

## Wspólne właściwości

Każdy element ma geometrię, warstwę Z, blokadę edycji, widoczność, style projektu i animację deklaratywną.

Do grupowania wielu elementów użyj funkcji **Group** w Designerze.
