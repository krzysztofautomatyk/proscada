# Tab Set

| Pole | Wartość |
|---|---|
| ID | `NAV-TABS` |
| Typ | `tab_set` |
| Plik | `catalog/navigation/TabSetWidget.svelte` |

Przełącza sekcje jednego widoku bez utraty kontekstu.

## Najważniejsze pola

`tabs`, `activeIndex` oraz opcjonalne `content:<label>`.

`tabs` jest listą CSV.

## Interakcja

Obsługiwane są kliknięcie, strzałki, Home i End. Roving tabindex utrzymuje poprawny focus.

## Quality

QualityBadge pozostaje widoczny, jeżeli kontrolka ma przypisany tag.
