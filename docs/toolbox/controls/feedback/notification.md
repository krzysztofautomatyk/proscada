# Notification

| Pole | Wartość |
|---|---|
| ID | `FDBK-NOTIFICATION` |
| Typ | `notification` |
| Plik | `catalog/feedback/NotificationWidget.svelte` |

Pokazuje niekrytyczny feedback lub komunikat kontekstowy.

## Warianty

`inline`, `toast`.

## Severity

`info`, `success`, `warning`, `error`.

## Najważniejsze pola

`variant`, `severity`, `title`, `message`, `dismissible`.

## Zasady

Notification nie jest alarmem procesu i nie zastępuje Alarm Managera. Dismiss jest lokalną interakcją UI.
