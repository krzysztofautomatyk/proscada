# Tooltip

| Pole | Wartość |
|---|---|
| ID | `FDBK-TOOLTIP` |
| Typ | `tooltip` |
| Plik | `catalog/feedback/TooltipWidget.svelte` |

Wyświetla pomoc, wartość lub dane diagnostyczne jako kontrolkę na canvas.

## Warianty

`help`, `value`, `diagnostic`.

## Najważniejsze pola

`variant`, `title`, `text`, `showAge`.

## Dane

Może prezentować quality label i age przypisanego taga.

## Dostępność

Informacja ważna operacyjnie nie może istnieć wyłącznie w Tooltipie. Musi być dostępna także w głównym widoku.
