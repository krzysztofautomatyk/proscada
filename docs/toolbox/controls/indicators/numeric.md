# Numeric Value

| Pole | Wartość |
|---|---|
| ID | `IND-VALUE` |
| Typ | `numeric` |
| Plik | `catalog/indicators/NumericValueWidget.svelte` |

Prezentuje bieżącą wartość procesową.

## Najważniejsze pola

`title`, `decimals`, `unit`, `fontTokenId`, `fontSize`, `fontWeight`, `textColor`, `titleColor`, `bgColor`, `align`.

## Dane

Wartość pochodzi z `tag.value`. Quality jest pokazywana w nagłówku. W Designerze bez taga widoczny jest placeholder.

## Zasady

Jednostka i precyzja muszą odpowiadać definicji taga. Nie używaj wielu miejsc dziesiętnych bez uzasadnienia procesu.
