# Disclosure Panel

| Pole | Wartość |
|---|---|
| ID | `LAY-DISCLOSURE` |
| Typ | `disclosure_panel` |
| Plik | `catalog/layout/DisclosurePanelWidget.svelte` |

Pokazuje zwijaną sekcję ekranu.

## Najważniejsze pola

`title`, `content`, `expanded`.

## Interakcja

Nagłówek jest przyciskiem z `aria-expanded`. Stan może być zmieniany myszą lub klawiaturą.

## Zasady

Nie ukrywaj w zwijanym panelu krytycznych alarmów ani podstawowych parametrów operacyjnych.
