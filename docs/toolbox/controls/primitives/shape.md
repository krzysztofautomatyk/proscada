# Rectangle / Shape

| Pole | Wartość |
|---|---|
| ID | `PRIM-RECT` |
| Typ | `shape` |
| Plik | `catalog/primitives/RectangleWidget.svelte` |

Buduje tło, obszar procesu i prosty kształt stanowy.

## Najważniejsze pola

`title`, `bgColor`, `borderColor`, `borderWidth`, `borderStyle`, `borderRadius`.

## Zachowanie

Kształt korzysta ze wspólnej widoczności, stylu projektu i animacji. Może być grupowany z innymi elementami.

## Zasady

Nie używaj jaskrawych kolorów jako dekoracji. Kolory alarmowe powinny pozostać zarezerwowane dla alarmów.
