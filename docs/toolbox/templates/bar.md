# Legacy Bar Graph

| Pole | Wartość |
|---|---|
| ID | `TPL-BAR` |
| Typ | `bar` |
| Plik | `catalog/indicators/LegacyBarWidget.svelte` |

Prosty poziomy pasek wartości zachowany dla istniejących projektów.

## Najważniejsze pola

`title`, `min`, `max`, `fillColor`, `bgColor`.

## Dane

Wartość taga jest ograniczana do zakresu i prezentowana jako wypełnienie.

## Status

Dla nowych projektów preferowany jest kanoniczny [Meter](../controls/indicators/meter.md), który obsługuje progi, gauge i quality.
