# Inflow K Controller

| Pole | Wartość |
|---|---|
| ID | `TPL-INFLOW` |
| Typ | `inflow_control` |
| Plik | `catalog/templates/InflowControlWidget.svelte` |

Kontroler współczynnika dopływu K dla Water Tank.

## Najważniejsze pola

`title`.

## Dane

Przypisany tag przechowuje wartość `K_x100`. Renderer zapewnia domenowe presety i write.

## Status

Szablon jest specyficzny dla demonstratora. Uniwersalne zadawanie wartości realizuje [Numeric Input](../controls/inputs/numeric_input.md).
