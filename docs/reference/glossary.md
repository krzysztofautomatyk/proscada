# Słownik

| Termin | Znaczenie |
|---|---|
| ACK | potwierdzenie alarmu przez operatora |
| Bad | niewiarygodna próbka |
| Coil | zapisywalny bit Modbus |
| Deadband | histereza ograniczająca chatter |
| Faceplate | szczegółowy widok jednego obiektu |
| FC | numer funkcji Modbus |
| Good | poprawna, świeża próbka |
| Holding register | zapisywalny rejestr 16-bit |
| Latching | zatrzymanie alarmu do resetu |
| LSB | najmniej znaczący bit; bit 0 |
| RMW | read-modify-write |
| RTN | return to normal |
| SCADA | nadzór, wizualizacja i operacje |
| Stale | próbka starsza od dopuszczalnego czasu |
| Tag | nazwany punkt danych procesu |
| Uncertain | jakość pośrednia, np. stara próbka |

## Nazwy plików

- `.proscada.json` — projekt;
- `.pscctrl` — eksport komponentu;
- `WidgetDef` — instancja kontrolki na ekranie.
