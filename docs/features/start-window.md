# Ekran Startowy (Start Window)

## Overview

Ekran Startowy ProScada (Start Window) wzorowany jest na interfejsie uruchomieniowym Visual Studio. Umożliwia szybkie zarządzanie historią projektów oraz inicjalizację prac inżynierskich.

## Funkcje

1. **Historia projektów (Recent Projects):**
   - Filtracja i wyszukiwanie tekstowe;
   - Przypinanie kluczowych projektów na górze listy (📌);
   - Usuwanie niepotrzebnych wpisów z historii;
   - Informacja o dacie i czasie ostatniego otwarcia.
2. **Kafelki szybkich akcji (Rozpocznij pracę):**
   - **Stwórz nowy projekt:** wybór nazwy, opisu i szablonu (Czysty vs Stacja Pomp Dual-Pump);
   - **Otwórz plik projektu:** wczytanie pliku `.proscada.json` z dysku;
   - **Importuj projekt:** bezkontaktowe zaimportowanie pliku projektu z walidacją schematu;
   - **Stacja Pomp Wodnych (Demo):** natychmiastowe załadowanie wbudowanego szablonu IEC 62443 / ISA-18.2.

## Dostęp i Skróty

- Dostępny w menu: `File -> Start Window / Ekran startowy...`
- Skrót klawiszowy: `Ctrl+Shift+W`
- Możliwość kontynuowania pracy w edytorze poprzez przycisk *Kontynuuj bez zmian*.
